# Project Documentation

This directory contains the engineering documentation for the Robotic Control & Visualization Software.

## Documents

- `PROJECT_REQUIREMENTS.md` — functional and non-functional requirements.
- `CLIENT_INPUTS_CHECKLIST.md` — hardware and technical information required from Aditya Sir.
- `ARCHITECTURE.md` — software architecture and layer boundaries.
- `HARDWARE_INTERFACE_SPEC.md` — controller communication contract template.
- `TEST_PLAN.md` — testing strategy and test cases.
- `ACCEPTANCE_CRITERIA.md` — measurable project completion criteria.
- `WEEKLY_DEVELOPMENT_PLAN.md` — detailed 10-week implementation plan.
- `DEPLOYMENT.md` — Ubuntu and Raspberry Pi deployment guidance.
- `CHANGELOG.md` — project changes and releases.
